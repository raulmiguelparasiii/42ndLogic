# OneLogic Mature Judgment Calculus

This file is the canonical compact formal overview. `paper/one_logic.md` gives the long-form explanation; `paper/main.tex` mirrors the paper; `formal/THEOREMS.md` records theorem obligations; `formal/one_logic/core.py` contains the finite executable semantics.

The mature calculus is not a stack of special modules for testimony, empathy, fallacies, debate, morality, or action. Those are projections and phenomena generated by one reality-relative recursive state.

## 1. Actual history

OneLogic is grounded in one actual time-indexed history:

```text
H_t = <omega_0, e_1, omega_1, ..., e_t, omega_t>.
```

The live model space does not replace actuality. It represents unresolved completions around what has actually transpired.

```text
G_t = Ground(H_t)
```

is the warranted relational structure currently recovered from that history.

`Ground` is an interface. ULT-style anonymous relational grounding may instantiate parts of it; unrestricted grounding is not assumed solved.

## 2. Material closure

For referent `r`:

```text
Qmat_t(r) = lfp MaterialClosure(G_t,r).
```

A distinction enters closure when varying it can alter mature judgment through currently known reality relations, including:

```text
informational grounding
contextual interpretation
real-world constraint
affected welfare
consequence
correction / answerability.
```

The closure expands when new reality reveals another governing distinction.

## 3. Live completions

Let `Omega_t` be the current represented completion class.

```text
K_t(r)
 = {m in Omega_t : m is compatible with G_t
                     and preserves Qmat_t(r)}.
```

A model outside `K_t` has been defeated by grounded reality or fails material adequacy.

## 4. One state

```text
One(H_t,r)
 = <G_t, Qmat_t(r), K_t(r), >=_t, I_t, A_t, T_t, D_t>.
```

`>=_t` is defeasible support, `I_t` inquiry, `A_t` feasible response, `T_t` transition, and `D_t` the deviation signature.

## 5. Strict consequence

For partial query `q`:

```text
K_t(r) |= (q=v)
iff
K_t(r) is nonempty
and every m in K_t(r) defines q(m)=v.
```

```text
C_t(r) = C(K_t(r)).
```

`C_t(r)` is the full categorical consequence set. OneLogic should derive all of it and no stronger categorical claim.

## 6. Provisional support

Let

```text
Max_t(r)
 = {m in K_t(r) : no live m' is strictly better supported}.
```

Then

```text
P_t(r) = C(Max_t(r)) \ C_t(r).
```

`P_t(r)` is the provisional consequence set. A claim in `P_t` is best-supported without being settled.

The unresolved residue is whatever `Qmat_t(r)` remains unsettled after correct grounding and inference. OneLogic does not preserve uncertainty for its own sake.

## 7. General bridge law

For proposed relation

```text
A=a -> B=b
```

define

```text
K[A=a] = {m in K : A(m)=a}
```

and

```text
D_B(A=a -> B=b)
 = {m in K[A=a] : B(m) is undefined or B(m) != b}.
```

The categorical bridge is valid exactly when the premise region is nonempty and `D_B` is empty.

This is the generative rule behind cases such as assumed ignorance, motive attribution, omission-as-denial, guilt-by-precaution, and coordination-from-agreement.

If a warranted measure `mu` is supplied:

```text
delta_B = mu(D_B) / mu(K[A=a]).
```

The measure is external warrant; OneLogic does not invent it.

## 8. Material representation loss

For representation `h`:

```text
D_M(h,r)
 = {(m,n,q) : h(m)=h(n), q in Qmat_t(r), q(m) != q(n)}.
```

Differences of definedness count.

```text
D_M(h,r) = empty
```

is material adequacy.

## 9. State deviation

For independently warranted state `W` and proposed state `M`:

```text
E-(W,M) = W \ M
E+(W,M) = M \ W.
```

This is the same deviation operator whether the object is a factual state, hypothesis set, source model, or one participant's model of another participant's position.

## 10. Correction debt

Let `C_t` be material available admissible corrections capable of changing a dependent judgment.

```text
D_C = C_t \ Integrated_t.
```

A correction defeated by stronger reality need not be integrated. A warranted material correction cannot remain excluded while the dependent judgment is still called exact.

## 11. Deviation signature

```text
D_t = <E-, E+, D_B, D_M, D_C>.
```

The zero vector of empty sets is exact relative to the represented referent. Componentwise inclusion provides a partial ordering of deviation without a fake universal scalar.

Finite implementations may report component counts. Domains with independently warranted measures may report component magnitudes.

## 12. Provenance

Evidence plurality means causal-informational plurality.

Repeated transmission with the same ancestry does not become independent corroboration. New observation, authentication, measurement, intervention, or a genuinely new testable transformation may create new ancestry.

Source continuity is persistence of undefeated source-related evidence in `G_t`, which may alter `>=_t` without replacing strict consequence.

## 13. Inquiry

Let `U_t(r)` be the material unresolved residue.

Each inquiry has:

```text
Gain(i) subseteq U_t(r)
Cost(i) = burden vector.
```

An inquiry is on the proportionate frontier when it has positive material gain, is available and admissible, and is not dominated by an inquiry with at least as much gain and no greater burden.

## 14. Response

For action `a`:

```text
F(a,r) = unresolved / sacrificed material pressures.
```

Correction-open `a` dominates `b` when

```text
F(a,r) proper-subset F(b,r).
```

The mature frontier contains correction-open nondominated responses. Nonempty residue is allowed when reality contains genuine tragic choice.

## 15. Recursive update

```text
H_t --e_(t+1)--> H_(t+1)
```

induces

```text
One(H_(t+1),r')
 = Correct(One(H_t,r), e_(t+1), omega_(t+1), r').
```

Correction may change `G`, `Qmat`, `K`, support, inquiry, response, deviation, or `Omega` itself.

If actuality no longer fits the represented class, expansion or replacement is required.

## 16. Debate as ordinary OneLogic

Let

```text
W_t(A)
```

be the warranted model of participant A's position from the actual debate history.

Let

```text
M_t(B->A)
```

be B's operative model of A, inferred from B's actual dependent arguments.

Then

```text
E-_t = W_t(A) \ M_t(B->A)
E+_t = M_t(B->A) \ W_t(A).
```

A hidden-state inference such as

```text
A failed to consider X
```

is simply a candidate bridge. It is categorical only if its `D_B` is empty.

## 17. Recursive frame lock

Suppose a material correction targets current opponent-model deviation. If the correction remains in `D_C` and the next dependent inference reuses the materially equivalent deviating model, the defect persists recursively.

Let `rho` be the consecutive number of targeted correction opportunities across which the equivalent defect survives and continues generating inference.

```text
rho > 0
```

measures persistence, not psychological motive.

A debate can therefore be formally diagnosed as talking past each other when opponent-model deviation does not shrink under available corrective contact and new arguments continue to be generated from that deviation.

## 18. Phenomenon signatures

These are labels for generated patterns:

```text
assumed ignorance
    -> bridge defect, often E+

manufactured position
    -> E+

caricature / frame substitution
    -> E- and/or E+, possibly D_M

omission-as-denial
    -> bridge defect

guilt-by-precaution
    -> bridge defect

corroboration inflation
    -> dependence/provenance defect

source reset
    -> unsupported exclusion of undefeated source evidence

silent adverse closure
    -> provisional state treated categorically while live defect remains

correction foreclosure
    -> D_C

recursive frame lock
    -> opponent-model deviation + D_C + rho>0

prejudice
    -> settled judgment while material closure remains unintegrated

good faith gone wrong
    -> truth-seeking aim/procedure + operative deviation + correction debt + recursive persistence.
```

The psychological explanation of a phenomenon remains a further query. OneLogic does not infer subconscious prejudice, strategy, or motive merely from the structural signature.

## 19. Stone and OGTS

Stone supplies the material criterion:

```text
purpose = affected welfare <-> real constraint
meaning = information <-> contextual interpretation
accountability = answerability <-> insulation.
```

OneLogic supplies the recursive judgment calculus.

An OGTS-compatible process is grounded in actual history, materially closed, categorically exact, dependence-calibrated, provisionally proportionate, inquiry-proportionate, response-nondominated, and correction-open, with no available alternative that reduces deviation without new material loss.

## 20. ULT interface

ULT-style grounding addresses:

```text
reality / expression / intervention
    <-> anonymous relational mathematics.
```

Stone constrains what material relations must remain governing.

OneLogic determines what those grounded relations warrant.

The current ULT empathy reality-contact result is a bounded operational instance of this interface, not unrestricted raw-reality grounding.

## 21. IEL compression

IEL is a discovery source. Its useful content is generated as follows:

```text
causal-information graph   -> G_t
provenance                  -> grounded ancestry
source weighting            -> >=_t
epistemic continuity        -> persistent undefeated evidence
provisional uptake          -> P_t
clarification               -> inquiry/correction
manufactured position       -> E+
caricature                   -> E-/E+ and D_M
correction refusal          -> D_C
precaution                   -> response under unresolved proposition
strategic observability      -> live latent-policy models
recursive belief             -> material closure depth
tragic choice                -> nondominated response residue
anti-self-sealing            -> legal model failure / expansion.
```

Non-identities remain useful as informal observations only when they point to a specific bridge that can be tested and measured.

## 22. Falsification

The mature calculus requires revision if a material phenomenon cannot be generated from actual history, grounding, material closure, live completion, support, bridge validity, deviation, inquiry/action, and recursive correction; if a nonempty bridge-defect set is compatible with categorical validity; if a material distinction is erased while `D_M` remains empty; if warranted correction can be ignored indefinitely while dependent judgment remains exact; or if a necessary maturity-relevant relation exists outside the current closure.
