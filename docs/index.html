OneLogic

A compact reality-tracking architecture for inference, inquiry, correction, and machine reasoning.

Preserve every possibility reality has not defeated.

Eliminate exactly what warranted reality-contact defeats.

Assert only what the survivors force.

If reality no longer fits the representation, revise the representation.

The semantic spine

Let 𝕄 be the represented space of structured possibilities, 1 ∈ 𝕄 actuality, and K ⊆ 𝕄 the live possibilities compatible with present warrant.

K ⊨ (q = v) iff K ≠ ∅ and ∀m ∈ K, q(m) = v

Inquiry is modeled by a transition relation. After an observed outcome, the sharp update retains exactly the modeled successors compatible with that outcome.

U*(K,o) = {m′ : ∃m ∈ K, (m,o,m′) ∈ T}

Objective deviation

Relative to an independently established ideal state I, a reasoning state A can fail in two directions:

unsupported exclusion = I \ A
unsupported retention = A \ I

This gives a content-neutral way to compare reasoning without reducing every error to a named fallacy.

OneLogic Solver

The solver is a non-transformer reasoning controller. Models may generate candidate hypotheses, but tools and observations determine which candidates remain live. If no live candidate survives, the controller requests model expansion instead of forcing an answer.

generate → represent → discriminate → observe → update → correct → repeat

Status

The repository includes bounded adversarial model search and general theorem statements checked in Lean. The architecture remains falsifiable: a legitimate reality-tracking operation that cannot be represented by the core is grounds to reopen it.
