# OneLogic Phenomenon Index

This index exists so a later analysis can refer directly to a named phenomenon while still grounding it in the general OneLogic calculus. The names are diagnostic labels, not primitives.

| Phenomenon | Canonical OneLogic signature | Paper section |
|---|---|---|
| Assumed ignorance | bridge defect `D_B`, often opponent-model `E+` | §21.1 |
| Manufactured position | opponent-model `E+` | §21.2 |
| Caricature / frame substitution | `E-` and/or `E+`, possibly `D_M` | §21.3 |
| Omission-as-denial | bridge defect `D_B` | §21.4 |
| Guilt-by-precaution | bridge defect from action to settled attribution | §21.5 |
| Corroboration inflation | provenance ancestry smaller than assumed independent evidence | §21.6 |
| Source reset | unsupported exclusion `E-` of undefeated source history | §21.7 |
| Silent adverse closure | provisional state treated categorically while live defect remains | §21.8 |
| Correction foreclosure | correction debt `D_C` | §21.9 |
| Recursive frame lock | opponent-model deviation + targeted `D_C` + persistence `rho>0` | §21.10 / §19 |
| Prejudice | closure while a materially governing distinction remains unintegrated | §21.11 / §8 |
| Good faith gone wrong | truth-seeking aim/procedure + operative deviation + `D_C` + recursive persistence | §21.12 / §22 |
| Talking past each other | opponent-model deviation fails to shrink under corrective contact while generating new dependent inference | §20 |
